# User Stories / Initial Product Backlog

This document outlines the user stories for the **MyClean** application. The stories are categorized based on user roles and reflect essential features for both customers and service providers.

---

## End-Users (Customers)

1. **Register and Log In**  
   As a customer, I want to register and log into the website so that I can access my personal dashboard and make bookings securely.

2. **Book a Cleaning Service**  
   As a customer, I want to book a cleaner for a specific date and time so that I can receive cleaning services conveniently.

3. **View My Bookings**  
   As a customer, I want to view my upcoming and past bookings so that I can manage my schedule.

4. **Cancel or Reschedule Booking**  
   As a customer, I want to cancel or reschedule a booking so that I have flexibility if my plans change.

5. **Rate and Review Service**  
   As a customer, I want to rate and review a cleaner after a service so that I can provide feedback and help others make informed choices.

---

## Service Providers (Cleaners)

6. **Accept and Manage Bookings**  
   As a cleaner, I want to view and manage all incoming bookings so that I can organize my workload efficiently.

7. **Profile and Service Setup**  
   As a cleaner, I want to update my availability, pricing, and services offered so that customers can understand what I provide.

---

## Shared Features

8. **Secure Payment (Mocked)**  
   As a user, I want to simulate a payment confirmation during booking so that the process feels complete and realistic.

9. **Role-Based Dashboard Access**  
   As a user, I want to access a dashboard tailored to my role (customer or cleaner) so that I only see relevant information.
