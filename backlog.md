# Feature Backlog

This backlog outlines the key features of the "MyClean" application, derived from the user stories. Each feature is listed with a brief description and priority level (10 = highest).

---

| Feature                              | Description                                                                 | Priority | Status    |
|--------------------------------------|-----------------------------------------------------------------------------|----------|-----------|
| User Registration and Login          | Allows users to create an account and securely log in to access the system | 10       | Planned   |
| Booking System                       | Enables customers to book cleaning services for a specific date and time   | 10       | Planned   |
| View Bookings                        | Displays upcoming and past bookings for users                              | 20       | Planned   |
| Cancel or Reschedule Bookings       | Allows users to manage existing bookings with flexibility                  | 20       | Planned   |
| Service Rating and Review           | Lets customers rate and review their experience                            | 30       | Planned   |
| Cleaner Booking Management           | Enables service providers to manage their assigned bookings                | 10       | Planned   |
| Cleaner Profile and Availability     | Allows providers to edit availability, services, and pricing               | 20       | Planned   |
| Role-Based Dashboard Access          | Custom dashboards for customers and cleaners based on login role           | 10       | Planned   |
